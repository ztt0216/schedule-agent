# 04 AI 使用说明

## 使用的工具

- **Claude Code**（模型 Claude Opus 5.5），在 Claude 桌面 App 中使用。

## AI 完成的部分

| 内容 | 说明 |
|---|---|
| 选题分析 | 对比四道题的验收点、风险和工作量，建议选第 1 题 |
| 方案设计 | 工具划分、护栏设计（save_draft / finish 两处）、幂等键设计、事实字段由代码生成 |
| 代码初稿 | `src/` 全部模块、`scripts/record_examples.py` |
| 合成数据 | `data/` 下的素材、规则、排期 |
| 测试 | `tests/` 下 26 个用例 |
| 文档初稿 | README 与 docs/01–05 |

## 个人修改与决策

如实说明：本项目的设计、代码、测试、文档和调试，都是由 Claude Code 在对话中完成的。我本人的工作如下。

- **选题**：把四道题的题面提供给 AI。看过 AI 给出的对比（验收点、风险、工作量、业务贴合度）后，选择了第 1 题。
- **模型与环境**：选择 DeepSeek 作为真实模型，并提供 API key（保存在本地 `.env`，不入库）。
- **调试**：两轮真实模型运行由 AI 执行；第一轮发现的 4 个问题，也由 AI 定位并修复（见 docs/03）。我确认了修复方向。
- **代码修改**：本人没有直接修改代码。
- **提交**：确认提交并推送到 GitHub。

## 验证方式

- `python -m pytest -q` 全部通过（26 passed）。
- 逐个阅读 `examples/mock/*.log`，核对每一步的观察结果与下一步动作是否合理。
- 真实模型（DeepSeek deepseek-chat）跑了两轮。第一轮暴露 4 个问题，修复后第二轮 12 个场景全部符合预期。详见 docs/03。
